🔐 Certificate Install Guide

Configure your device to trust the IR Proxy CA

📡 Proxy settings

⬇ Download .pem (macOS)
  1. 1Download ir-proxy-ca.pem using the button above.
  2. 2Double-click the file — Keychain Access opens automatically.
  3. 3Find IR Proxy CA in the list and double-click it.
  4. 4Expand the Trust section → set When using this certificate to Always Trust.
  5. 5Close the window and enter your macOS password when prompted.
  6. 6Configure your Wi-Fi proxy: System Settings → Wi-Fi → Details → Proxies → HTTP Proxy. Enter the server IP and port shown above.
⬇ Download .cer (iOS)
⚠️ Apps with SSL pinning will still reject the proxy certificate even after installation.
  1. 1On your iPhone/iPad, open Safari and navigate to:
    http://<proxy-ip>/__admin/proxy/ca.cer
  2. 2Tap Allow when prompted to download a profile.
  3. 3Go to Settings → General → VPN & Device Management and tap the IR Proxy CA profile.
  4. 4Tap Install and follow the prompts, entering your passcode if required.
  5. 5Go to Settings → General → About → Certificate Trust Settings.
  6. 6Toggle IR Proxy CA to enable full trust.
  7. 7Configure proxy: Settings → Wi-Fi → (your network) → Configure Proxy → Manual. Enter the server IP and port above.
⬇ Download CA (.pem) ⬇ network_security_config.xml
⚠️ Apps targeting Android 7+ (API 24+) ignore user-installed CAs by default. You need to add the network_security_config.xml to the app's source code, or root the device.
  1. 1On your Android device, download ir-proxy-ca.pem using the button above (open this page in the device browser).
  2. 2Go to Settings → Security → Encryption & Credentials → Install a Certificate → CA Certificate.
  3. 3Select the downloaded ir-proxy-ca.pem file and confirm the installation.
  4. 4Configure proxy: Settings → Wi-Fi → (long-press your network) → Modify Network → Advanced Options → Proxy → Manual.
  5. 5For the target app (API 24+): download network_security_config.xml, place it at app/src/main/res/xml/network_security_config.xml, and add android:networkSecurityConfig="@xml/network_security_config" to the <application> tag in AndroidManifest.xml.
⬇ Download .pem (Windows)
  1. 1Download ir-proxy-ca.pem and rename it to ir-proxy-ca.crt.
  2. 2Double-click the .crt file → click Install Certificate → select Local Machine.
  3. 3Choose Place all certificates in the following store → click Browse → select Trusted Root Certification Authorities → OK → Finish.
  4. 4Or via Administrator Command Prompt: 
    certutil -addstore root ir-proxy-ca.crt
  5. 5Configure proxy: Settings → Network & Internet → Proxy → Manual proxy setup. Enter the server IP and port above.
