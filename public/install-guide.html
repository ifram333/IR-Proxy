3 · Install & trust it

  1. Tap Download above — iOS saves a configuration profile.
  2. Open Settings → Profile Downloaded and tap Install (top right), then enter your passcode.
  3. Now the important bit: Settings → General → About → Certificate Trust Settings.
  4. Turn ON the switch next to IR Proxy CA.

Installing the profile is not enough on its own — HTTPS keeps failing until the trust switch in step 4 is on.

  1. Tap Download above to save the .pem file.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate, then confirm the warning.
  3. Pick the downloaded ir-proxy-ca.pem.
  4. Verify under Trusted credentials → User — it should list IR Proxy CA.

Android 7+ apps ignore user-installed CAs unless the app opts in. For your own builds, add the network security config to the app.
